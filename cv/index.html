02

Research Highlights

Shadow-FT: transferring fine-tuning updates

Equal contribution

Studies weight similarity between paired base and instruction-tuned models. Fine-tuning updates learned on the base model are transferred to its instruction-tuned counterpart.

View publication ↗

PTQTP: low-bit LLM inference

Equal contribution

Decomposes weights into two ternary trit-planes for multiplication-free inference. Reports 4.63-fold higher end-to-end generation throughput than FP16 for LLaMA-2 7B on an RTX 3090 (batch size 1; 512 input and 512 generated tokens).

View publication ↗

LoCa: logit calibration for distillation

First author

Calibrates teacher logits for misclassified samples to improve knowledge distillation with limited additional computation.

View publication ↗

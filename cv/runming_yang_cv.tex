\begin{rSection}{在研项目 / Ongoing Research}
\begingroup
\fontsize{11}{16}\selectfont
\textbf{\href{https://rummyyang.github.io/research/opd/opd_deck.html\#1}{On-policy 蒸馏：思考模式的迁移及其与 RL 的衔接}}\quad 香港大学 | 博士阶段研究\hfill 2026.09 - 2026.10\\[2pt]
以 Qwen3 0.6B / 1.7B / 4B 为学生、8B 为教师，围绕教师提示模式、生成预算与终止行为设计对照，准确率为 MATH-500 avg@4。
\begin{itemize}[itemsep=4pt,topsep=5pt]
\item \textbf{思考教师突破常规 OPD 的收益饱和。} 非思考教师 OPD 的增益随学生规模递减，在 4B 上降至零，改用思考模式教师后，16K 预算下，1.7B / 4B 相对基座仍提升 13.3 / 9.5 个百分点。 \mbox{\href{https://rummyyang.github.io/research/opd/opd_deck.html\#7}{[规模对照·第7页]}}
\item \textbf{行为分析支持学生自身思考模式的迁移。} 32K 预算下，1.7B / 4B 分别达 90.9\% / 95.2\%，接近各自思考模式，三个尺寸的自蒸馏也取得相近表现。学生的逐题正确率轮廓与自身思考模式更一致、与外部教师的相关显著更低，支持收益可来自已有思考能力的调用。 \mbox{\href{https://rummyyang.github.io/research/opd/opd_deck.html\#2}{[思考上限·第2页]}}
\item \textbf{区分“会做题”与“及时交卷”。} 1.7B 在 2K 截断后追加 32 tokens 强制作答，准确率从 17.8\% 回升至 72.8\%，结合答案后的 p(EOS) 与续写行为，分别诊断预算不足和答后不停，分析教师停止信号的迁移，并探索按参考模型分段的一步式修正。 \mbox{\href{https://rummyyang.github.io/research/opd/opd_deck.html\#3}{[预算·第3页]}} \mbox{\href{https://rummyyang.github.io/research/opd/opd_deck.html\#6}{[终止·第6页]}}
\item \textbf{刻画 OPD 起点对 RL 的收益与压缩代价。} 相同下游 RL 设置下，OPD+RL 的 1.7B 在 16K 预算上达 87.3\%，高于直接 RL 的 81.7\%，短程 RL 进一步揭示训练窗口的影响：窗口越窄，长度压缩越强，长预算下的竞赛题准确率损失也越大。 \mbox{\href{https://rummyyang.github.io/research/opd/opd_deck.html\#3}{[RL预算·第3页]}} \mbox{\href{https://rummyyang.github.io/research/opd/opd_deck.html\#5}{[短程RL·第5页]}}
\end{itemize}

01LoCa纠正教师监督，同时保留类别关系⌄

LoCa: Logit Calibration for Knowledge Distillation

arXiv:2409.04778v1, 2024-09-07；论文标注 ECAI 2024 accepted

直观讲解

教师输出虽有整体知识，其单个预测仍可能错误。监督 CE 要提高真实类别概率，而错误教师的 KL 可能反向指导。作者称其为 mis-instruction。目标是在修正预测方向的同时保住非目标类别中蕴含的 dark knowledge。

关键机制

p 为教师 softmax 概率；g 为真值类别；p_m=max_i p_i。仅当教师 top-1 不等于 g 时校准。

正确预测保持不变；把校准后的教师分布代入原有 KD（KL 与 CE 组合）。归一化及非目标类别比例均保留，无新增可学习参数。α 越接近 1，目标与最大非目标之间的强制间隔越小。论文称 logit calibration，但推导中的 p 是概率，面试不要把概率缩放混同于原始未归一化 logit 缩放。

关键表达
s = α / (1 − p_g + p_max)，0<α<1
关键表达
非目标类：p′ᵢ = s pᵢ；目标类：p′_g = 1 − s(1−p_g)
关键表达
p′_g − max_{i≠g} p′ᵢ = 1−α > 0
关键表达
非目标类比例保持：p′ᵢ / p′ⱼ = pᵢ / pⱼ

边界与需要核对的条件

  • 分析性边界：方法依赖可信真值。噪声标签或生成任务的一对多合理答案会削弱强制参考 token 为最高概率的合理性。
  • α 是目标类别与最大非目标类别的间隔控制，具体最佳值依赖设置；不要把固定 α 当作无条件最优。
  • 与 Simple-OPD 的错误 CoT 结果并不冲突：一个校准逐 token/类别蒸馏目标，一个研究后续 on-policy 训练的行为初始化；不能推出错误监督一般有益。

面试问答

为何不丢弃错误教师样本？
会同时丢失有用的非目标类别比例信息；LoCa 的设计目标是保留这些信息。
为何不交换真值和最大类别的概率？
交换改变非目标类别之间的相对比例；统一缩放则保持它们。

与其他工作的区别

唯一直接改变教师目标分布的一篇；可以在概念上与损失选择或参数效率方法组合，但不能声称未报告的组合已有实验验证。

02Adaptive KL按头尾分布误差调整蒸馏方向⌄

Rethinking Kullback-Leibler Divergence in Knowledge Distillation for Large Language Models

COLING 2025 正式论文，2025.coling-main.383，pp. 5737–5755；优先于 arXiv:2404.02657

直观讲解

FKL/RKL 的渐近最优解不足以解释实际蒸馏的有限步数差异。作者把差异定位于教师概率分布头部与尾部的早期拟合速度，提出按当前未拟合误差调整优化侧重。

关键机制

p 为教师、q 为学生在相同 prefix 上的 token 分布。H 为按教师概率降序累加达到阈值 μ 的头部集合；论文默认 μ=.5。

头尾差异决定两个完整词表 KL 的权重；不是仅在 H 上算 FKL、仅在尾部算 RKL。作者代码对用于权重的学生概率 detach，避免权重本身的反向传播改变目标解释。

关键表达
本文 p 为教师、q 为学生：FKL = Σp log(p/q)；RKL = Σq log(q/p)
关键表达
g_H = Σ_{v∈H}|pᵥ−qᵥ|；g_T = Σ_{v∉H}|pᵥ−qᵥ|
关键表达
L_AKL = [g_H/(g_H+g_T)] FKL + [g_T/(g_H+g_T)] RKL

理论条件：p=q 的结论针对可自由优化、正概率的每个上下文 logits。共享神经网络参数和有限容量可能无法同时实现所有上下文的 p=q，因此不能据此声称所有 FKL/RKL 训练的最优参数和动态完全一致。

指标：ROUGE-L

FKL 26.93±.09；RKL 27.89±.08；等权 FKL+RKL 30.48±.10；AKL 31.05±.17

边界与需要核对的条件

  • 作者明确未验证 70B 等更大模型；主要实验证据来自 GPT-2 和 LLaMA-6.7B 教师，不能声称规模普适。
  • 需要教师完整 token 分布并计算词表头尾误差；tokenizer 对齐和完整分布开销是扩展到异构或黑盒教师时的问题。
  • 论文以累计质量至少 μ 定义最小头部；作者代码用 cumulative_sum > μ 的掩码并保证首项进头部，阈值跨界 token 的归属有细小差异。重现实验时应明确采用论文还是代码实现，并处理总误差接近零的数值稳定性。

面试问答

为什么高斯 mode-seeking 图示不能直接代表离散词表蒸馏？
应解释分布参数化和可达解空间，再讨论有限训练动态，不能仅回答因为是离散分布。
为什么不用固定等权？
表 1 的直接对照支持自适应权重进一步提升；但幅度远小于只与 FKL 比较的提升。
为何 detach 权重？
让权重描述当前误差而不允许模型通过操纵权重降低目标；论文公式和代码实现应分别说明。

与其他工作的区别

保留教师分布和学生参数化，改变分布距离的动态权重；LoCa 改目标、LLM-NEO 改参数、ProFit 改参考监督掩码、Simple-OPD 改训练起点。

03LLM-NEO只训练低秩参数，也能接收软监督⌄

LLM-NEO: Parameter Efficient Knowledge Distillation for Large Language Models

arXiv:2411.06839v2，2025-02-25

直观讲解

把监督来源和可训练参数化拆开：SFT/LoRA 的硬标签信息与 KD 的教师软分布是不同维度，低秩参数更新也可以接收 KD 信号。

关键机制

对学生低秩更新应用标签和教师软分布的联合目标，减少需训练参数及其梯度/优化器状态。合并增量后保留原学生尺寸。论文以 L_KL(z_t,z_s) 表示 KL，方法重点并非新散度。

关键表达
W_student = W₀ + ABᵀ；冻结 W₀，仅训练 A、B
关键表达
L = α CE(y,q_student) + (1−α) KL(p_teacher,q_student)

训练参数：§3.2 搜索 rank={2,4,6,8,16,32,48,128,256} 和学习率 {1e-4,2e-4,5e-4,1e-3}；§3.3 采用 rank 128、初始 lr 2e-4。更高 rank 通常更强，但通常需要较低学习率；不能把这一趋势当无条件规律。

面试问答

是否只是 LoRA+KD？
应坦诚机制就是将已有软监督和低秩更新结合，论文价值主要在统一视角、调参规律和成本/性能实证；不要包装为全新 KD 散度。
减少哪些显存？
学生可训练参数的梯度/优化器状态减少；教师权重和前向、学生基础权重与激活仍有成本。
rank 太低为什么可能失败？
限制更新子空间与知识迁移容量；rank 太高削弱参数效率并改变合适学习率。

与其他工作的区别

唯一主要改变 KD 可训练参数的一篇。与 Simple-OPD 虽都用 LoRA，但 NEO 的低秩更新承担蒸馏本身，Simple-OPD 的低秩更新仅准备后续 OPD 的初始行为。

04ProFit让哪些参考 token 产生梯度⌄

ProFit: Leveraging High-Value Signals in SFT via Probability-Guided Token Selection

Findings of ACL 2026 正式论文，2026.findings-acl.755，pp. 15383–15401；优先于 arXiv:2601.09195

直观讲解

SFT 单一参考序列对多种有效响应实施排他式监督，可能过度压制表达多样性。低概率目标 token 通常引发较强的更新，而这些 token 并非都携带任务核心信息。作者用可廉价计算的模型概率代理监督价值。

关键机制

概率来自当前训练中的学生，使用完整参考 prefix；掩码每步随模型更新，阈值固定。只屏蔽损失，并未从输入中删掉低概率 token。训练本身不需额外教师；§4.1 用 Gemini-3-pro 标注语义 token 是诊断分析，不是 ProFit 训练必需组件。作者仓库示例 τ=.1，但不能据代码示例推断所有表格配置均相同。

关键表达
pₜ = πθ(y*ₜ | x,y*_<t)
关键表达
Mₜ = 1[stopgrad(pₜ) > τ]
关键表达
L_ProFit = E[−(1/T) Σₜ Mₜ log pₜ]

理论条件：§4.3 在局部 Jacobian 满行秩且最小奇异值至少 γ>0 的假设下，给出 ||grad_theta ell|| >= gamma(1-p_y)。这是下界；仅比较下界不能证明任意两个 token 的实际梯度范数必定按概率反序。

诊断证据：§4.1：Qwen3-4B-Base 的 core/trivial token 平均概率 .768/.485，统计检验 p≈1e-6。这是所分析数据上的相关性，不是高概率与重要性普遍等价的证明。

  • 对梯度定理的条件和结论保持精确，避免将相关性和下界解释为语义因果证明。

面试问答

为什么选高概率而不是难 token？
作者的解释是避免不必要的大幅分布迁移，优先保留所研究任务的核心监督；高概率本身并不意味着每个 token 都更重要。
高阈值的代价是什么？
§6.1 中 GPQA 可能下降，长尾实体通常低概率；创作/多样性任务的重要 token 也可能低概率。
训练信号更少为何有效？
减少某些不必要的分布迁移，而非增加教师知识；需要结合基座能力与数据规模回答，弱模型/全新知识可能不同。

与其他工作的区别

改变 SFT token 的损失掩码，不校准教师、不引入 KL、自身不要求 LoRA，也不是 OPD。与 Simple-OPD 的共同点是关心已有能力与后续训练的兼容，但作用位置不同。

05Simple-OPD为 on-policy 蒸馏准备兼容的起点⌄

Simple-OPD: Demystifying Warm-up for On-policy Distillation

arXiv:2608.06802v1，2026-08-07

直观讲解

OPD 在学生产生的轨迹上查询教师，师生推理行为和前缀分布兼容性影响监督质量。过往常把 SFT warm-up 当成例行步骤，本文分解 CoT 来源、正确性、更新容量、预热长度四个因素。

关键机制

  • 从下游 OPD 提示分布采样，用同一个教师生成 CoT。
  • 进行受限容量的 LoRA SFT 预热，选择接近饱和的训练时长；分析使用 rank 16/32/64 等低秩设置。
  • 将 adapter 合并成初始化检查点，继续原有 OPD；Simple-OPD 不要求替换 OPD 的散度或其他核心目标。
关键表达
预热：用后续 OPD 的同一教师生成 CoT，进行 LoRA SFT
关键表达
L_OPD = E_{x,ŷ~πθ}[ (1/|ŷ|) Σₜ KL(πθ(·|x,ŷ_<t) ‖ π_T(·|x,ŷ_<t)) ]

配置口径：附录 A：warm-up batch 16，全量 SFT lr 5e-6、LoRA lr 5e-5；OPD global/minibatch 128、每提示 rollout 1、prompt 2048/response 8192、温度 1、lr 1e-6。配置中的额外 KL regularizer 系数 0 不能误读为没有蒸馏 KL。

消融的适用范围：§3 消融的学生为 Qwen3-1.7B-Base、教师为 DAPO-Math17K 上训练的 Qwen3-8B-Base，75 步 OPD；这不是表 1 的 4B 教师设置。正确/错误 CoT 的下游四数学任务均分约 35.2–36.5；结论应限定在这里。同教师 CoT 优于异来源 GPT-5.5 CoT 的比较不能归因于教师质量单一因素。

面试问答

为什么错误 CoT 也能帮？

06Shadow-FT在 Base 学增量，再移植给 Instruct⌄

Shadow-FT: Tuning Instruct Model via Training on Paired Base Model

arXiv:2505.12716v3，2025-09-26；24页。

直观讲解

把Base当作学习新任务的代理：在Base上学增量，再把同一增量加到已有Instruct上。

Instruct虽善于遵循指令，继续对小规模任务数据SFT可能收益很小甚至退化；配对Base缺乏现成对齐行为，但可能更容易吸收新任务。论文发现Base/Instruct权重相近，尝试分离学习增量的位置和执行任务的骨干。

关键机制

  1. 需要同一架构、对应参数坐标的Base与由它得到的Instruct。先用普通Full-FT或LoRA训练Base，得到W_B^+。
  2. 计算ΔW=W_B^+-W_B，再形成W_I^+=W_I+ΔW；LoRA时可以把在Base上训练得到的低秩分支合并进Instruct。部署是一个模型，没有双模型推理。
  3. 与Chat Vector的参数算术可等价重写为W_B^+ +(W_I-W_B)；论文贡献应表述为针对Instruct继续调优退化的观察、训练路径选择和实证，而不是声称首创所有task-vector加法。
  4. 图5给出Qwen3-8B LoRA训练的loss/gradient动态作为机制证据，但这是经验解释，不是权重近似即可保证增量可迁移的定理。
权重相对差异（Eq.1）
σ = Σ|W_B − W_I| / (Σ|W_B| + Σ|W_I|)

求和逐元素进行；Llama3.1-8B约0.016。这个比值不是有1.6%的参数发生变化。

Shadow-FT（Eq.2–3）
W_I⁺ = W_I + [Tune(W_B) − W_B]

普通FT对应W_I+(Tune(W_I)-W_I)；改变的是计算更新的起点。

07Timber按谱方向细化后训练增量⌄

Timber: Training-free Instruct Model Refining with Base via Effective Rank

arXiv:2509.23595v1，2025-09-28；17页。

直观讲解

对Base→Instruct的权重增量做谱分解，保留主要方向、减弱尾部方向，尝试恢复探索而保住一次回答能力。

后训练把概率集中到高回报回答，可能提升Pass@1却限制大k下的探索。论文用Base/Instruct权重的有效秩近似不变作为动机，希望无需新数据和梯度训练，部分回退后训练更新。

关键机制

  1. 对每个线性层计算ΔW=W_I-W_B，而非直接分解完整W_I。
  2. SVD得到ΔW=U diag(σ_i)V^T；按奇异值由大到小排列，令K=ceil(eRank(ΔW))。保留前K个，剩余乘λ。
  3. λ=0为Timber-L；0<λ<1为Timber。只处理线性层权重，不处理bias或norm。主实验从{0.2,0.5,0.8}选择λ，正文说按AIME'24选择。
  4. 与全局插值W_B+μΔW不同：Timber只衰减尾部奇异方向，而非均匀缩放所有后训练更新。它本身不减少最终模型参数量或推理FLOPs。
有效秩（Eq.1，γ=1）
pᵢ = σᵢ / Σⱼσⱼ；eRank(ΔW) = exp(−Σᵢ pᵢ log pᵢ)

衡量奇异值谱的有效维度；谱集中时低、均匀时接近实际rank。

谱细化（Eq.2–7）
W′ = W_B + U diag(σ₁,…,σ_K, λσ_K₊₁,…,λσᵣ)Vᵀ；K = ceil(eRank(ΔW))

K向上取整；文中一处写non-decreasing与Top-K语义冲突，教学应按保留最大的K项理解。

09PTQTP用双三值平面改写权重表示⌄

PTQTP: Post-Training Quantization to Trit-Planes for Large Language Models

arXiv:2509.16989v3, 2026-01-01

直观讲解

二值权重只能取正负状态，容易把近零连接也强行放大；重新预训练三值模型又很贵。PTQTP 的思路是用两张能相互补偿的三值平面，兼顾表达力与加减、查表执行。

关键机制

  1. 把每个权重近似为 α₁t₁+α₂t₂，其中每个 t 都可取 −1、0、1。第二平面负责补偿第一平面遗漏的细节，0 状态允许关闭不必要连接。
  2. 每 128 个权重为一组。固定平面时，求解 2×2 岭回归得到两个缩放；固定缩放时，对每个权重枚举 9 种三值对并选重建误差最小的一种。
  3. 按条件数自适应调整正则，最多 50 次迭代；主配置停止阈值 10⁻⁴，不需要任务校准或训练微调。
  4. 推理将激活与小块三值模式的部分和预存到 LUT。查表和加减减少乘加开销，但缩放和网络其他模块仍有算术操作。
双平面表示
Ŵ = diag(α₁)T₁ + diag(α₂)T₂；Tₖ ∈ {−1,0,1}
缩放更新
αᵢ = (SᵢᵀSᵢ + λᵢI₂)⁻¹ Sᵢᵀwᵢ
实际存储：附录式 (16)
M = 2nd × 2 + ceil(d/G) × 2n × 16 bits；G=128 时约 4.25 bit/线性权重

为什么无激活校准也能工作，代价是什么？
直接最小化权重重建误差，部署简单；但权重Frobenius误差不是激活加权输出误差，对高敏感方向没有明确任务感知保护。

与其他工作的区别

与 LieQ 的层级精度分配不同，PTQTP 改变权重表示；与 FluxBin 不同，它采用统一三值平面而不另设重要列残差分支。

10FluxBin联合设计压缩表示与查表内核⌄

FluxBin: Flexible LUT-based Ultra-low-bit LLM Inference by Algorithm-Kernel Synergy

arXiv:2608.15602v1, 2026-08-16

直观讲解

模型文件变小，并不保证推理变快：反量化、重复浮点运算和重要权重的稀疏访存，都可能吃掉收益。FluxBin 同时设计权重表示与 CUDA 内核，让压缩位流可以直接用于执行。

关键机制

  1. 以若干二值基近似权重，每个基同时有行缩放和列缩放。交替最小二乘求缩放，联合枚举二值符号，而非只做贪心残差分解。
  2. 用校准激活估计 Hessian，按列重要度在每组 128 列中选 8 或 16 列；为这些列额外拟合残差基。默认校准样本数为 256。
  3. 将列缩放融入激活 LUT 构建。每个 μ 位二值权重模式就是表地址，读取部分和后再做行缩放与累加。
  4. Virtual Columnar Mapping 将逻辑稀疏的重要列存为物理连续矩阵，同时收集对应激活和缩放，复用全局分支的 GEMV 内核。主配置 μ=8，LUT 有 256 种局部模式。
行列二值分解
Ŵ = Σₖ (αᵣ⁽ᵏ⁾ α꜀⁽ᵏ⁾ᵀ) ⊙ B⁽ᵏ⁾ + 重要列的残差分支；B⁽ᵏ⁾ ∈ {−1,+1}
列重要度
Sⱼ = Σᵢ Wᵢⱼ² / ([H⁻¹]ⱼⱼ)²；H ≈ 2XXᵀ
带列缩放的查表项
LUT[p] = Σₙ (xₙ α꜀,ₙ) × (2bₙ(p) − 1)

边界与需要核对的条件

  • 二值算法未必自动加速：需要压缩位流直接索引LUT，避免先解压到FP16再调用常规GEMV。
  • 行列缩放让一个二值基的幅值更灵活；列缩放若逐权重重复执行会很贵，必须在LUT构建阶段与激活融合。
  • LUT大小含2^mu项，mu=8意味着256种模式；较大mu降低查表次数却提高共享内存占用，可能降低occupancy。
  • hybrid结构提供精度，但需salient输入gather和额外LUT分支；VCM解决存储/执行不规则，不是让保护分支免费。
  • 不要把nvidia-smi GPU util接近100%解释成浮点算术单元利用率100%；正文明确它是device-busy fraction。

11LieQ把有限位宽分给关键层⌄

Exploring Layer-wise Information Effectiveness for Post-Training Quantization in Small Language Models

Findings of ACL 2026, final pp15753–15764

直观讲解

小模型冗余少，极低位宽的损失经常集中在少数关键层。逐层删去再测困惑度很贵，逐权重保护又会破坏规则布局；LieQ 用表示几何近似功能敏感度，再按层分配位宽。

关键机制

  1. 对同一代表性 hidden state，分别计算训练权重投影 Z=Wh 与随机初始化对照 Z̃。对两者做 SVD。
  2. 将奇异值平方归一化后计算指数谱熵；数值越小表示能量越集中。用相对紧凑度变化，在投影类型和注意力头上平均，得到层分数。
  3. 按分数给预算允许的少数层 4-bit，其余 2-bit。主实验常只保护最高分的一层，因此平均位宽略高于 2。
  4. 层内保持统一格式，可结合 GPTQ/AWQ 等后端。免去了逐层困惑度探测，但仍需要代表性前向得到激活。
谱能量与有效秩
pₖ = σₖ² / Σⱼσⱼ²；R(Z) = exp(−Σₖ pₖ log pₖ)
层评分
sℓ = 平均[1 − R(Z) / R(Z̃)]；分数越高，越优先保护
等大小层的位宽分配
f = (平均位宽 − 2) / 2；m = round(fL)；最高分 m 层用 4-bit，其余用 2-bit

  • R数值越小才越“紧凑”；论文名称Compact(Z)实际上是指数谱熵/有效秩，要避免方向说反。

  • Top1保护时平均bit近似2+2/L；不是所有权重严格2bit。对于不等大小层、取整预算，部署前仍需检查实际字节数。

面试问答

为什么小模型收益尤其明显？
其关键功能集中于少数敏感层，均匀压缩会破坏这些瓶颈；保护少量层即可显著降低损失。更大模型的重要性分布较平坦，单层保护的边际作用减弱。
它与GPTQ/AWQ是什么关系？
LieQ主要是层级精度调度原则，可与量化后端组合；GPTQ/AWQ解决给定位宽下如何近似权重，两者处于不同决策层级。

与其他工作的区别

LieQ 回答“把更多精度给谁”，而不是重新发明权重编码。它与 PTQTP/FluxBin 作用层次不同，不能仅比较一个名义 bit 数就判断优劣。

13LLMs on Memristors器件噪声、推理可靠性与能耗的取舍⌄

Can We Trust LLMs on Memristors? Diving into Reasoning Ability under Non-Ideality

COLM2026; arXiv:2603.13725v2, 2026-10-02

直观讲解

忆阻器存内计算能减少数据搬运，但器件误差会扰乱推理。更隐蔽的代价是模型复读、迟迟不输出答案，令原本节能的硬件生成大量无效 token。论文研究这种质量、长度与能耗的耦合。

关键机制

  1. 将权重分为 64×64 块，用每块最大绝对权重缩放高斯扰动；用 BF16 七位尾数随机翻转近似故障。主实验 p=0.01，σ 从 0.005 到 0.02。
  2. Qwen3-0.6B 上，每种配置 5 次独立运行，每题采样 8 次，最长 32k 输出；软件评测使用 8 张 H200。
  3. 比较 thinking、2-shot ICL 和模块多副本求平均。thinking 低噪声较好，高噪声会格式崩溃；ICL 控制长度但损失一些准确率。
  4. 重复 Attention/FFN 或浅层并求平均可降低扰动；是并行副本平均，而非把同一层串联四次。能耗/面积采用 RRAM、XPESim 与数字操作成本模型估算。
每个权重块的扰动
W*块 = W块 + N块 × max|W块|；N块各元素 ~ N(0,σ²)
多副本平均的直觉（有条件）
若 r 个副本误差独立、零均值，则平均误差方差约为 σ²/r。

相关噪声、系统偏差和固定故障会削弱这个收益；这不是所有物理器件的保证。

14The Art of Efficient Reasoning让短且正确的轨迹成为有效训练信号⌄

The Art of Efficient Reasoning: Data, Reward, and Optimization

arXiv:2602.20945v3，arXiv修订日期2026-03-20；21页，PDF首页显示March23。

阅读拓展：用于建立联系和形成研究问题，不列入本人论文成果。

直观讲解

高效推理不是把回答压短就成功：要让训练中持续出现‘短且对’的正例，并保留区分‘短且错’的信号。

只设计长度奖励或只看平均输出长度，会把模型不再推理误认为提速。要同时研究prompt难度、采样数量、负样本处理与优化的新旧策略差异，并在多个推理预算下看正确率。

关键机制

  1. 这是统一协议下的配方与训练动态研究，不是提出新架构。主分析骨干DeepSeek-R1-Distill-Qwen-1.5B，DeepScaleR数学prompt，GRPO；学习率1e-6，clip-high0.28，prompt batch128，初始N=8，rollout上限L_R=16k、目标L_T=4k。
  2. 训练分两阶段：先适应长度，输出与熵快速下降；随后长度大致稳定但正确率继续恢复/提高。若只观察早期变短，无法判定是否真正学会高效推理。
  3. 使用8次rollout估计题目难度，pass rate>0.5为Easy，≤0.5为Hard。主实验只训Hard易缺少正例并崩溃；Easy使正确短回答更常被发现，长度学习更稳定。N从8增至12/16/24有利但增加采样成本，代码任务增益未必同样明显。
  4. 四类回答必须分开：短且对、长且对、短且错、长且错。基础截断奖励只给短且对1，其余0。mask掉所有错误回答，只留下短对与长对，会让长度替代正确性成为捷径；同时mask长对和短错，也使短/对和长/错高度混淆。
  5. mask长且对通常保留更多质量但回答变长；mask全部长回答，长回答没有被惩罚，后期可能重新增长。取L_R=L_T，在生成阶段便限制到目标长度，是主分析中较好折中。它不是‘把长回答剪短就当正确’，最终答案仍需verifier。
  6. 研究off-policy staleness S∈{2,4,8,16}，即使用较旧策略采样来更新当前策略；易题+N24下可加快训练但高S有熵上升/长度反弹风险。最终Qwen3扩展实验不使用off-policy。
  7. 评估不仅报告一个预算：2k/4k/8k/16k/32k下的Mean@8、Pass@8，以及按正确性条件分组的长度分布。硬预算下优秀的策略可能在宽预算下损害能力。
基础正确性奖励（Eq.1）
R_vanilla(x,y) = 1[答案正确]

只关心答案正确，未直接压缩长度。

截断奖励（Eq.2）
R_T(x,y) = 1[答案正确] × 1[长度 L(y) ≤ L_T]

L_R控制最多采多少token，L_T控制长度合格阈值；二者不同。

解释零奖励为何仍是负信号（通用GRPO示意，非文中新增公式）
Aᵢ ≈ (Rᵢ − 组内平均奖励) / (组内奖励标准差 + ε)

组中有正例时，R_i=0的轨迹可获得负advantage，仍参与优化；mask是从相关损失贡献中排除，二者不可混称。全0/全1组没有结果奖励的组内对比信号；KL等其他项仍可能存在。

为什么增加rollout有帮助（独立二值reward的教学近似）
P(至少一个正例) = 1−(1−p)^N；P(正负混合组) = 1−p^N−(1−p)^N

p是某题单次产生正reward的概率。增加N提高发现正例/得到组内对比的机会，但不自动改变正例比例的期望p。不能把样本数增加说成在固定策略下单次正确率提高。

RL Starts before RL: On Policy Distillation for Better Reinforcement Learning

arXiv:2609.28145v2，2026-09-26；25页。

阅读拓展：用于建立联系和形成研究问题，不列入本人论文成果。

直观讲解

蒸馏后的即时分数并不足以衡量它是否是好的RL起点：更接近教师的完整分布、又保留替代路径，可能使后续RL学得更好。

常见做法把SFT/OPD结束时准确率最高的模型作为最好初始化，但后续RL依赖起始策略会探索什么、哪些轨迹获得奖励。论文把终点评价延伸到同样RL之后。

关键机制

  1. 比较同一学生的Base→RL、SFT→RL、OPD→RL。Text学生Qwen3-8B/教师Qwen3-32B；VL为Qwen3-VL-8B/32B，教师均经过RL。主比较OPD使用RKL。这里Base是未经过本文准备阶段的起始学生，不宜擅自等同某个发布名带-Base的纯预训练checkpoint。
  2. SFT学verified teacher responses的硬token；OPD先让学生自己生成，再让教师在学生走过的prefix上提供完整词表分布，做逐token KL。学生有机会在自己的错误状态上得到教师反馈，减轻只看teacher路径的分布偏移。
  3. 准备和RL数据分开：text用100K OpenMathInstruct准备、17K DAPO-Math RL；VL准备100K OpenMMReasoner，RL为16K DeepMath与MMK12/VisionR1。八个text/二十个VL基准均等权平均。
  4. 在VL另做2×2因子实验：prefix来自student(OPD)还是teacher(TFD)，局部loss是RKL还是FKL。四种都用full teacher distributions，TFD不是硬标签SFT。
  5. VL配置Table4：准备1epoch、lr1e-5、global batch1024、seed42；后续GRPO每prompt10响应、T1/top-p1、max response16384、lr1e-6、actor KL0.01、seed1。后续RL训练设置一致，但不是总算力相等的比较。
  6. 机制探针在1024个RL-pool题、每题64次生成上估Pass@k；再看各策略自身prefix上的top20归一化JS、top1一致率和词表规则匹配位置的熵。论文将其称作可能解释，未完成因果拆分。
局部FKL/RKL（Appendix A.2；本笔记p=学生、q=教师）
p 为学生，q 为教师：RKL = Σₐ p(a)log[p(a)/q(a)]；FKL = Σₐ q(a)log[q(a)/p(a)]

方向由谁在KL左边决定，和谁生成整条response是两个独立选择。

轨迹来源与token目标的通用分解（教学写法）
L(ρ,D) = E_{x,y~ρ}[ (1/|y|) Σₜ ℓ_D(pₜ,qₜ) ]

ρ决定访问哪些prefix，ell_D决定在同一prefix怎样对齐分布。OPD的ρ是学生，TFD的ρ是教师；ell_RKL与ell_FKL分别采用上一式的方向。

完整轨迹KL的链式法则（理论补充）
KL(Q‖P) = E_{y~Q} Σₜ KL(qₜ‖pₜ)；KL(P‖Q) = E_{y~P} Σₜ KL(pₜ‖qₜ)

不作每条长度归一化并把终止视作token时的标准链式法则。学生prefix上的FKL通常不是完整轨迹FKL，因为外层访问分布不同。

边界与需要核对的条件

  • 论文明确把准备成本和总训练compute排除在比较指标之外；不能声称此配方是计算最优。
  • Table4给出stage-specific固定seed，不是多随机种子训练误差；bootstrap区间用于固定checkpoint上诊断prompt采样，不等于训练方差置信区间。
  • 按熵/奖励/输出不连贯监测停止训练，不能把共享配置描述成完全等步数、等总计算预算。
  • top20 JS/entropy是截断且重新归一化的局部分布探针，不是完整词表KL，更不是完整轨迹分布距离。各策略prefix不同，探针兼有访问状态和局部分布影响。
  • strategy entropy来自固定词汇规则，不能等同语义层面的独立推理策略数量；熵高也可能是无效噪声。
  • FKL后续RL优势的直接对照在本文VL模型对/二十基准；机制仍需固定prefix、干预熵/对齐、跨模型多seed来验证。

面试问答

on-policy是否等于reverse KL？
不是。on-policy说rollout由当前学生生成，FKL/RKL说在该prefix比较两个下一token分布的方向。本文学生prefix+FKL也是OPD。
为什么即时分数低的FKL可能更适合RL？
论文观察其更接近教师局部分布且保留较高熵，可能留下可供奖励进一步筛选的路径；此处是解释性假说，不能把概率质量/可学习性简化成熵越高越好。
和AKL是否矛盾？
不矛盾。AKL研究局部蒸馏拟合动态并在其基准评价蒸馏结果，本篇评价另一模型族的后续RL；任务、prefix、容量和终点评价都不同。
怎么设计下一步公平实验？
固定teacher、数据、访问prefix、总训练token/compute和下游预算，比较FKL/RKL/AKL，多seed；分开干预分布对齐和熵，才能检验原因。此为建议实验，非论文现有结论。

与本人论文的联系

  • 与Simple-OPD的层级：Simple-OPD是LoRA warm-up→OPD；本篇是OPD→RL。两个‘before’相接但优化终点不同，不能据此说Simple-OPD已经证明最终RL收益。可提出warm-up→OPD→RL组合假设，但必须实测。
  • 本篇Related Work明确引用Simple-OPD以及AKL。它不是Runming Yang的论文，引用关系不能当作者关系。
  • 与AKL：AKL在相同prefix根据teacher分布头/尾的student gap自适应加权FKL和RKL，改变的是局部loss。AKL没有自动决定prefix采样来自谁，也没有在原论文中证明这种混合最适合后续RL。
  • 不要简化为FKL必然mean-seeking、RKL必然mode-seeking：两者局部分布自由时最优点同为p=q，有限容量、优化过程和prefix访问分布才使实验不同；AKL原论文也强调LLM词表分布下早期头/尾拟合行为，反对不加条件套用高斯直觉。

简短术语表

SFT
监督微调：给定提示与参考回答，通常最小化参考 token 的交叉熵。
KD
知识蒸馏：学生学习教师输出的分布或其他知识；不只模仿一个硬标签。
OPD
On-policy distillation：学生生成轨迹，教师在学生访问过的前缀上提供监督。它不等于某个固定 KL 方向。
RL
强化学习：按奖励优化生成策略；奖励可来自答案验证或偏好模型等。
LoRA
低秩适配：冻结基础权重，只学习低秩更新；减少训练状态，不自动减少基础模型推理参数量。
PTQ / QAT
PTQ 是训练后量化；QAT 是训练中考虑量化。若 PTQ 后又做微调，完整流程并非完全免训练。
PPL
困惑度，越低通常越好；必须在相同数据、tokenizer 和评测协议下比较。
Mean@8 / Pass@8
Mean@8：八次采样的平均正确率。Pass@8：至少一次答对的覆盖率，需要额外选择机制才能用到正确候选。
Vote@8
对八次采样进行投票后的准确率；不能与 Mean@8 或 Pass@8 互换。
FKL / RKL
蒸馏中常把 KL(教师‖学生) 称 FKL，KL(学生‖教师) 称 RKL。先明确符号，再看轨迹来自谁。
LUT / GEMV
查找表 / 矩阵—向量乘法。权重模式可索引预计算部分和，但查表、缩放和访存都有成本。
百分点 / 相对变化
准确率 40%→50% 是增加 10 个百分点，或相对提升 25%；不能混用。

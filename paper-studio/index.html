工作台使用说明

  1. 先聊方向

    在「讨论与反馈」留下整体意见，选择全项目或某一篇论文。可以回复、修改自己的意见。

  2. 每轮都有结论

    项目负责人明确要求优先；未定事项参考小小黑的反馈，由 Codex 核实并执行。意见会显示待讨论、已采纳、已落实或待你确认。

  3. 材料与成果归档

    上传原稿与修订稿，保留具名版本。需要时再打开稿件做细节批注。

  4. Codex 每小时更新

    整点任务读取新意见，在原来的 Codex 任务继续处理，再把进度和新稿放回来。电脑与 Codex 需要保持运行；离线后以实际补同步结果为准。

讨论和稿件不写入个人 GitHub 仓库。工作台用独立云端数据库与文件存储；归档不是删除，删除也不承诺立即清除云服务商的备份。请妥善保管邀请链接。

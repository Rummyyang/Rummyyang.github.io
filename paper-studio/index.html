一起把论文改好

  1. 选择论文和版本

    左侧切换三篇小论文，上方切换中文、英文和投稿润色稿。当前只有示例，正式内容会在收到原稿后更新。

  2. 像批注一样提出建议

    选中文字或点击段落旁的按钮，右侧会引用对应内容。也可以直接写全文评论。

  3. 发布、回复与解决

    填写后点击「在 GitHub 发布」，在新窗口确认提交。每条批注有独立讨论页；登录 GitHub 即可回复，仓库维护者或批注作者可以关闭已解决的讨论。

  4. 预览你手中的文件

    支持 PDF、Markdown 和 TXT。本地预览不会上传，其他人看不到，也不能对该预览发布共享批注。需要共享时，由维护者将稿件发布到这个页面。

页面和 GitHub 讨论都是公开的。正式稿件发布前，请确认适合公开。草稿只保存在当前浏览器。

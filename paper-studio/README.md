# 小小黑的论文协作工作台

访问：https://rummyyang.github.io/paper-studio/

这是 GitHub Pages 上的纯静态协作页面。包括三篇论文、中文/英文/投稿润色版本、段落与选中文字批注、全文评论、回复读取、已解决筛选和本地文件预览。初始内容全部是明确标记的示例或空状态，没有实际论文。

## 评论怎样协作

1. 读者选中文字（同一段内）或点击段落旁按钮，在右侧写评论。
2. 点击「在 GitHub 发布」，在新窗口登录 GitHub 并确认创建 Issue。页面不会代替读者自动提交。
3. 回到工作台点击刷新。每条批注保存为当前仓库的一条 Issue，回复也保存在 GitHub。
4. 点击「回复 / 处理」在 GitHub 回复或关闭讨论。关闭后，页面归入「已解决」。

不要求安装 GitHub App，不使用 PAT，不要求读者拥有仓库写权限。机器标记位于 Issue 正文中：`<!-- paper-studio:v1 {...} -->`，请保留它。提交 URL 不设置标签，避免普通读者的权限问题。若手动删除标记，批注不会出现在工作台，但仍保存在 Issues。

评论按论文和语言版本隔离；不同修订版本的评论会显示「历史版本」。修订稿保留永久段落 ID，便于找到原位置；移除的段落会显示「原段落已移除」。Issue 已发布与否以 GitHub 提交结果及刷新后的列表为准，打开提交页不代表发布成功。

匿名读取公共 GitHub API 有频率限制（通常每 IP 每小时 60 次），页面缓存 3 分钟、只手动刷新，不持续轮询。一次读取至多三页，每页 100 条仓库 Issue；更多记录通过「加载更早的讨论」读取。失败时保留已读取数据并给出提示，页面顶部也可直接进入 GitHub。

## 添加正式稿件

编辑 `papers.json`，提交到 `main` 后，GitHub Pages 自动更新。

- `papers[].id`：稳定论文标识，保留 `paper-1`、`paper-2`、`paper-3`。
- `name` / `subtitle` / `journal`：论文名称、描述、拟投期刊。
- `stage`：0 中文拆分，1 英文翻译，2 投稿润色。
- `versions.zh` / `versions.en` / `versions.journal`：三个稿件版本。
- 每次发布正文修订应更新版本 `id`（例如 `zh-v1`），更新 `label`（例如 `中文稿 v1 · 2026-10-01`），将 `status` 设为 `published`。
- `sections` 中每节有 `id`、`title`、`paragraphs`；每段有永久 `id` 和纯文本 `text`。段落 ID 限英文、数字、连字符、下划线和点，长度不超过 100。版本 ID 同理且不超过 80。
- 修改已有段落时保留原 ID；删除后不要把同一个 ID 分配给无关内容。中英文对应段落可使用同一 ID。
- 如需嵌入 PDF，把文件放在 `paper-studio/manuscripts/`，在版本中增加 `"pdf": "./manuscripts/paper-1-zh-v1.pdf"`。PDF 批注为全文评论，请在评论中注明页码；推荐同时维护文字稿以使用段落定位。

示例版本对象：

```json
{
  "id": "zh-v1",
  "label": "中文稿 v1",
  "status": "published",
  "title": "实际论文标题",
  "subtitle": "作者与修订信息",
  "sections": [
    {"id": "abstract", "title": "摘要", "paragraphs": [
      {"id": "abstract-01", "text": "这里填写正式摘要。"}
    ]}
  ]
}
```

本地预览支持 PDF（30 MB 内）、TXT / Markdown（1 MB 内）。Markdown 仅显示标题和文本段落；公式、表格等完整排版请用 PDF。文件不上传、不持久保存、不共享；退出本地预览后即可继续评论线上稿件。暂不支持 Word 或自动翻译，后续由维护者发布拆分稿、译稿和期刊润色稿。

## 安全与可见性

页面、正式发布的稿件及评论均公开。`noindex` 仅请求搜索引擎不收录，不是访问控制。正式论文公开前请确认作者同意及投稿安排；若需要私密协作，应改用具备服务器端访问控制的方案。GitHub token 不应写入源码、浏览器存储或网页表单。

评论和稿件以纯文本渲染，不执行其中的 HTML。API 链接限制到当前 GitHub 仓库，外链使用 `noopener noreferrer`。草稿与公开评论缓存保存在当前浏览器 localStorage，本地预览文件仅在当前页面内存中。

## 本地运行

在仓库根目录执行 `python3 -m http.server 8765`，打开 `http://localhost:8765/paper-studio/`。无需依赖安装和打包。

主页只新增进入此子页面的导航链接，原有页面和资源保持原样。
